# NO Button

A giant red button that says NO. Expo (React Native + TypeScript) for iOS, Android and web/PWA.

Play it: https://zenigmax.github.io/no-button/ (Add to Home Screen for the offline app).

- `npm install && npx expo start`: run in dev
- `python3 scripts/build_web.py`: build the offline PWA into `dist/` plus a single file `NO-Button.html`
- See PUBLISHING.md and STORE_LISTING.md for the App Store / Play release.
